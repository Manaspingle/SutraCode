def fetch_user_data(user_id):
    url = f"https://api.example.com/users/{user_id}"
    # Hangs indefinitely on dropped packets!
    response = requests.get(url)
    return response.json()
Evidence-Grounded Correction
def fetch_user_data(user_id):
    url = f"https://api.example.com/users/{user_id}"
    # Specified connection & read timeouts
    response = requests.get(url, timeout=(3.05, 10))
    response.raise_for_status()
    return response.json()
Grounded Citation:
"Nearly all production requests should specify a timeout parameter to avoid hanging threads indefinitely... If no timeout is specified, Requests will wait forever for a socket response."
